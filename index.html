Autotube Engine

Autotube Engine is a personal automation tool that produces and publishes short-form videos to YouTube channels owned and operated by its developer.

What it does

The tool reads public technology news feeds, drafts a short narration script, synthesizes a voiceover, assembles a vertical video with stock footage and captions, and uploads the finished file to one of the operator's own YouTube channels:

  • @SecurityBytesDaily — cybersecurity news
  • @TerminalMastery — Linux & the terminal

Use of the YouTube API

This application uses the YouTube Data API v3, and its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The only scope requested is youtube.upload, used solely to upload videos to the operator's own channels. No data is read from, or shared with, any third party.
